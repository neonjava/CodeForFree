# Contributing

Issues and pull requests are welcome. Before a large change, open an issue describing the user problem and proposed approach. Keep provider integrations within documented APIs and their usage terms. Do not commit credentials, account sessions, private project content, or generated database files.

Run `cargo fmt --check`, `cargo check`, and `cargo test` before opening a pull request. Explain behavior changes and how you tested them. Report vulnerabilities privately as described in SECURITY.md.
